# SyncTranslate - Android Клиент

Нативный Android-клиент для системы голосового перевода в реальном времени **SyncTranslate**.
Приложение захватывает аудио с микрофона, устанавливает сессию с бэкендом для перевода и воспроизводит синтезированный ответ.

## Архитектура (в двух словах)

Приложение построено на современных технологиях Android (**Kotlin, Jetpack Compose, Coroutines, Hilt**) и использует два различных протокола для своих задач:

1. **HTTPS (Retrofit):**
   Используется для одноразовой, надежной загрузки образца голоса пользователя во время первоначальной настройки.

2. **WebRTC (Google):**
   Используется для основной функции — низкозатратной потоковой передачи аудио в реальном времени на сервер и обратно.

## Схема работы

```text
+-------------------+      HTTPS POST /train/voice (WAV-файл)     +-------------------+
|                   | -------------------------------------------> |                   |
|  Android Клиент   |                                              | Бэкенд (HTTP)     |
|  (Фаза настройки) | <------------------------------------------- | (для загрузки)    |
|                   |                Ответ 200 OK                  |                   |
+-------------------+                                              +-------------------+

+-------------------+          WebRTC (Сигналинг через WS)         +-------------------+
|                   | <==========================================> |                   |
|  Android Клиент   |                                              | Бэкенд (Сигналинг)|
| (Фаза реального  | <------------------------------------------> |                   |
|      времени)     |            WebRTC (Медиа через SRTP)         | (Медиа-сервер)    |
+-------------------+                                              +-------------------+
```

## Аудио

* **Запись входного аудио:**
  16 кГц, моно, 16-бит PCM (управляется `AudioRecord` для файла и **WebRTC** для потока).

* **Воспроизведение выходного аудио:**
  Полученные данные 16 кГц апсэмплятся до 48 кГц для более качественного звучания.

* **Протокол реального времени:**
  **WebRTC** с использованием **SRTP (Secure Real-time Transport Protocol)** для медиа, обычно поверх **UDP**.
